# FR3-d1

##### _The "official" "tool" of the OIAR_

## What is this?

A spoiler-free tool to search and read The Magnus Protocol episodes. If you've used my other project, [Archivists' Assistant](https://github.com/Lunas-Lab/Archivists-Assistant), this is the same as that, but for The Magnus Protocol rather than The Magnus Archives. You tell it where in the series you are up to, and it will let you search through and read any episode transcripts you've already read _**without**_ revealing any information you haven't already seen

## How do I use this?

Simply download the installer from the right (just under where it says 'Releases'), extract the zip file and then run 'Install.bat' and follow the prompts it gives you. It will update as new episodes release and automatically get them, as well as any updates released by me
